# Rogue Trader 3rd Edition

This is an _unofficial_ system for playing **FFG's Rogue Trader 1e** on [Foundry VTT](https://foundryvtt.com/), using **Dark Heresy 2nd Edition** mechanics as its rules base and progressively migrated to RT 1e canon. (The "3rd Edition" in the name refers to the system iteration, not a game edition.) It is compatible with Foundry VTT **v13–v14**.

It offers extensive support for character sheets, compendium packs, and automated rules resolution to save you time and let you focus on role playing.

## Features

🗡️ **Compendium packs** sourced from the RT Core Rulebook, Into the Storm, and the Living Errata v1.4 — weapons, weapon mods, armour, talents, traits, psychic powers, cybernetics, ammunition, tools, attack specials (Tearing, Toxic, Corrosive, …), consumables & drugs, ship components/weapons/traits, and 300+ NPCs.

🧭 **Origin-Path character creation** — Home World → Birthright → Lure of the Void → Trials and Travails → Motivation → Career, with the background traits as real drag-drop items that apply their effects.

⚔️ **Automated RT 1e combat engine** — to-hit & Degrees of Success, damage/penetration/armour, hit locations, weapon special qualities, the personal Critical Effect tables, Righteous Fury, a clickable condition layer (Stunned, Prone, On Fire, …), Dodge/Parry reactions, cover, grappling, and two-weapon fighting.

🔮 **Psychic powers** — Fettered/Unfettered/Push casting, Psychic Phenomena & Perils of the Warp, Force weapons, and per-Degree-of-Success scaling.

🚀 **Vehicles & void-ships** — facing-armour vehicle damage with the Vehicle Critical chart, plus Strategic-Round void-ship combat (initiative, the Manoeuvre/Shooting economy, VU range bands & firing arcs, ramming, and boarding).

💰 **Campaign layer** — group Profit Factor, the Acquisition Test, and Endeavours (sized objectives, excess-AP→PF, the per-session Misfortune roll).

🧰 **Inventory & macros** — drag-and-drop to build weapons from mods and ammunition, stow gear on your ship to reduce encumbrance, and drag weapons/skills to the macro bar; range and target size are factored into attacks automatically.


## Install
 - Go to the setup page and choose _Game Systems_.
 - Click the _Install System_ button, and paste in this manifest link: `https://raw.githubusercontent.com/antipop001/rogue-trader-3rd-vtt/main/src/system.json`
 - Create a Game World using the "Rogue Trader 3rd Edition" system.
