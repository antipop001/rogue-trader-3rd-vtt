In Rogue Trader, every creature has a defined size category, which appears in its stat block as part of its Traits (the Size Trait). A human is the baseline "Average." If a creature doesn't have one listed explicitly, the GM assigns one by comparing it to known examples.


A reference for digital tabletop setups (Foundry, Roll20, etc.) mapping Rogue Trader's Size Trait to Pathfinder 2e size categories and token dimensions.

Map scale: **1 square = 1 metre** (per Rogue Trader Core Rulebook, p. 236).

## VTT Setup Notes

**Hulking as Medium.** An Ork Nob is taller and broader than a human but still fits a single 1m square. If your VTT supports it and you want visual differentiation, scale the token art to ~1.2× while keeping the 1×1 occupied space.

**Beyond Gargantuan.** PF2e officially caps at Gargantuan (4×4), so Monumental and Titanic don't have a strict equivalent. Most VTTs let you set custom token dimensions — just bump them as needed.

**Tiny tokens.** PF2e Tiny mechanically occupies a full square but visually takes half. For RT, Miniscule/Puny creatures are usually environmental or carried items, so 0.5×0.5 art on a 1×1 token works fine.

## Tactical Reminders

- **Engagement, not adjacency.** RT doesn't define melee through "adjacent square." You're engaged when you're within reach — larger footprints threaten further out.
- **Point Blank = 2m.** Anyone within 2 squares is at Point Blank for ranged attacks (+30 BS).
- **Size and movement.** Apply the size modifier to AB first, *then* other modifiers. Base movement can never drop below 1.
- **Grappling.** Larger combatant gets one extra degree of success per size category difference on Opposed Tests within the grapple (Core p. 249).
